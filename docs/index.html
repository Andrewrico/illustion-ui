Introduction

Illustion UI is an atomic CSS framework with utility class names and variants such as lg: and hover:. Accessibility values are stored in CSS variables. The widget changes those variables and sets data-ax-* attributes on <html>.

When a setting is automatic, the operating system preference is used.

The framework is tied to the W3C WAI rules: every feature maps to WCAG 2.2 success criteria, checked against W3C's own data, and a sync script reports when W3C changes them. See Tied to W3C WAI and WCAG.md.
