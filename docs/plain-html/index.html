Plain HTML, already styled

Write semantic HTML with no classes and it already looks finished. src/elements.css styles headings, text, lists, quotes, code, keys, tables, forms, buttons, disclosure and dialogs, all from tokens, so every widget mode applies. It sits in the base layer at zero specificity: any utility or component class wins. The signature: one display serif for headings, a short primary bar that marks a new thought (h2, hr), primary bullets and numbers, and keys that look like keys.
