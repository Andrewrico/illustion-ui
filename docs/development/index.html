Development

Node.js 22 or later is required.

npm test
npm run test:browser
npm run check
npm run dev
npm run docs

npm test runs the unit tests: contrast of every token pair in all themes, utility class names and values, variants, layers, the content scan, the Eleventy plugin, the widget state helpers and the WCAG mapping.

npm run test:browser runs 111 Chromium checks: axe-core (WCAG 2.2 A/AA) in 6 theme and mode states with the widget open, keyboard flow, persistence, reflow at 320px with 200% text, grid columns per breakpoint, large-text: and the switcher at 200% text, the stretched link, OS preference fallbacks, identical computed styles between the content-scanned CSS and the full bundle, the atomic grid against grid.css at five widths, per-page builds against the full bundle, web components / shadow DOM, variable utilities (breakpoints, large text, hover, no inheritance, revert-layer fallback), and the compiled demo (inline and shared-stylesheet) against the readable source in four modes.

npm run check runs both test commands. npm run wcag:sync checks for W3C rule changes.

The site has three parts: index.html is the landing page, examples.html is the long component demo that the browser checks run against, and docs/ is this README rebuilt in the layout of getbootstrap.com/docs (top bar, sidebar, breadcrumb, "On this page"). npm run docs regenerates docs/ from README.md; edit the README, never the generated pages. The look is in docs/assets/site.css. The default theme is black and white, set in src/tokens.mjs. The browser check also runs axe on the landing page and four docs pages in four themes.

The development server runs at:

http://127.0.0.1:8094
