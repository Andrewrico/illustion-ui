Ways to connect

CSS#

Load the full or minified stylesheet.

<link rel="stylesheet" href="./dist/illustionui.css">
<link rel="stylesheet" href="./dist/illustionui.min.css">

Load the init script in <head> if saved widget settings should apply before the first paint.

<script src="./dist/illustionui-init.js"></script>

The init script can be inlined. It must not use defer or async.

npm exports#

Export Contents
illustion-ui Full CSS.
illustion-ui/min Minified CSS.
illustion-ui/init The init script.
illustion-ui/widget The widget and its state helpers.
illustion-ui/widget.min The widget bundled and minified (9.9 KB gzipped).
illustion-ui/atomic The atomic engine: create, props, classes, inject.
illustion-ui/shadow adopt, AtomicElement for web components.
illustion-ui/core The shared core CSS for per-page builds.
illustion-ui/vars Token references for style objects.
illustion-ui/grid The atomic grid styles.
illustion-ui/auto The automatic widget entry point.
illustion-ui/tokens Token definitions.
illustion-ui/build The build API, including build and minify.
illustion-ui/eleventy The Eleventy plugin.

CSS imports from JavaScript need a bundler that handles CSS (Vite, esbuild, webpack).

import "illustion-ui";
import "illustion-ui/min";
import { mount } from "illustion-ui/widget";
import "illustion-ui/auto";
import { build, minify } from "illustion-ui/build";
import a11yAtomic from "illustion-ui/eleventy";

Command line#

Build CSS from scanned content.

npx illustion-ui --content "_site/**/*.html,src/**/*.js" --out css/site.css

The content option accepts comma-separated file patterns. The content build writes minified CSS.

The package also provides the npm run build:site script.

Scan JavaScript files that build class strings. This includes src/widget.js.

Node API#

import { build, minify } from "illustion-ui/build";

const css = await build({
  content: [
    "_site/**/*.html",
    "src/**/*.js",
  ],
});

const minifiedCss = minify(css);

Eleventy plugin#

import a11yAtomic from "illustion-ui/eleventy";

eleventyConfig.addPlugin(a11yAtomic, {
  out: "css/illustionui.css",
});

The plugin scans the built HTML after each build.

Widget#

Load the automatic entry point.

<script type="module" src="./src/auto.js"></script>

Or mount the widget manually.

import { mount } from "./src/widget.js";

const widget = mount();

Use one method, not both.

Manual attributes#

Set data-ax-* attributes directly on <html>.

<html lang="en" data-ax-text="150" data-ax-theme="dark">

CSS variable overrides#

Override framework variables in CSS.

:root {
  --ax-spacing: 0.3rem;
  --ax-a11y-target-min: 44px;
}

A variable can also be scoped to one element.

.card {
  --ax-spacing: 0.2rem;
}
