Atomic engine — one declaration per class

This card is styled with create(), Facebook/StyleX style. Every property becomes one generated class holding one declaration. Hover it, or change text size or contrast in the widget: the classes stay the same, the variables they read change.

const s = create({
  card: {
    padding: vars.space[6],
    borderRadius: vars.radius.lg,
    backgroundColor: {default: vars.color.surface,
                      ':hover': vars.color['surface-2']},
    flexDirection: {default: 'row', '@large-text': 'column'},
    gap: vars.space[4],
  },
});
card.className = classes(s.card);
