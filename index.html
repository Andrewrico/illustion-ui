Atomic CSS · CSS variables · WCAG 2.2

Every class bends to the reader.

Utilities read CSS variables. The accessibility widget changes those variables, so text size, spacing, contrast, fonts and motion adapt across the whole page — no extra markup.

Accessibility modes

Text size

100–200%. Scales the root font size, so rem-based spacing and the grid scale too (1.4.4).

Contrast & theme

Light, dark and two high-contrast themes, all tested for 4.5:1 or 7:1 (1.4.3, 1.4.6).

Text spacing

Exact 1.4.12 values: letters 0.12em, words 0.16em, paragraphs 2em.

Motion

Durations multiply by --a11y-motion; stop it or follow the OS (2.3.3).

Fonts & links

Readable or dyslexia-friendly fonts, highlighted links, left-aligned text.

Focus & targets

Strong focus outline, 44px targets (2.5.5) and a large cursor.

Grid

1 column on mobile, 2 on tablet, 3 on laptop, 4 on desktop — set with .cols-t-2 .cols-l-3 .cols-d-4 on .grid__wrapper.
