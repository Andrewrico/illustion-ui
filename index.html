Build sites every reader can use

Illustion UI is an atomic CSS framework with familiar utility classes, powered by an accessibility widget. A reader picks 200% text, and every class follows. Each feature maps to a WCAG 2.2 criterion.

Get started any way you want

Link the stylesheet, import the pieces you need, or compile a whole site. Pick the one that fits, then keep the rest for later.

  • Include the CSS

    One stylesheet and a tiny init script that applies saved settings before the first paint.

    <link rel="stylesheet"
  href="./dist/illustionui.css">
<script src="./dist/illustionui-init.js"></script>

    All the ways to connect

  • Add the widget

    One module mounts the settings panel. Readers choose text size, contrast, fonts, spacing and motion.

    <script type="module"
  src="./src/auto.js"></script>

    Widget JavaScript API

  • Compile for production

    Turn every class into a one-declaration atomic class in one shared, cacheable stylesheet.

    npx illustion-ui --site "_site/**/*.html"

Write plain utility classes

Utility names and variants, like p-4, lg:grid-cols-3 and hover:bg-primary. Every value reads an accessibility variable, so text size, spacing, contrast and motion change everywhere at once.

  <button class="ax-bg-primary

  </button>

Everything you need, nothing in the way

Six parts that work together. Use all of them, or only the ones you want.

  • Accessibility tokens

    Spacing, type, colour, focus, target size and motion are CSS variables. The widget changes them and the whole page follows.

    Tokens

  • Atomic engine

    create() turns each style into one class holding one declaration, in the style of Facebook's StyleX.

    Atomic engine

  • Your grid, unchanged

    The andrewrico grid.css drives layout, with a compiled atomic twin and utility classes on top.

    Grid

  • Variable utilities

    One class per property reads a chain of variables, one per breakpoint, each falling back to the one below.

    Variable utilities

  • Only what the page loads

    A content scan keeps just the classes a page uses. The scanned page renders identically to the full bundle.

    Only what the page loads

  • Tied to W3C WAI

    Every feature maps to WCAG 2.2 success criteria, and a sync script reports when W3C changes them.

    Tied to W3C WAI

Twelve accessibility modes, one attribute each

The widget stores only non-default settings and sets a data-ax-* attribute on <html>. Automatic settings follow the operating system.

  • Text size

    100% to 200%. Type, spacing and the grid scale together.

    WCAG 1.4.4

  • Theme

    System, light or dark.

    WCAG 1.4.3, 1.4.11

  • Contrast

    System, standard or high.

    WCAG 1.4.6

  • Font

    Default, readable or dyslexia-friendly.

    WCAG 1.4.8, related

  • Text spacing

    1.8 line height, wider letters, words and paragraphs.

    WCAG 1.4.12

  • Motion

    Stop animation and transitions, or follow the system.

    WCAG 2.2.2, 2.3.3

  • Focus

    A 5px focus outline with a 3px offset.

    WCAG 2.4.7, 2.4.13

  • Target size

    Interactive targets at least 44 by 44 pixels.

    WCAG 2.5.8, 2.5.5

  • Links

    Underlined and highlighted, never colour alone.

    WCAG 1.4.1, related

  • Saturation

    Full, low or grayscale.

    WCAG 1.4.1, related

  • Alignment

    Left-align headings and text blocks.

    WCAG 1.4.8, related

  • Cursor

    A large 48 by 48 pixel cursor.

    Motor accessibility, related

Accessibility modes in the docs

Customize with CSS variables

Utility classes read framework variables. A widget mode changes the variable, and the class stays the same. Override any variable in your own CSS to make Illustion UI yours.

How it works · Cascade layers

.p-4 {
  padding: calc(var(--ax-spacing) * 4);
}

html {
  font-size: calc(100% * var(--ax-a11y-text-scale));
}

[data-ax-text="150"] {
  --ax-a11y-text-scale: 1.5;
}

The best idea from each framework

Illustion UI borrows one proven idea from each of these, and says where it came from.

  • Bootstrap

    The stretched link: the whole card is clickable, and the focus ring wraps the card.

  • Every Layout

    The switcher stacks at a threshold in rem, so larger text stacks sooner.

  • Utopia

    Fluid space tokens that grow smoothly from 320px to 1440px.

  • Open Props

    A spring easing built from a linear() curve.

  • Material Design

    State layers for hover, focus and press on any background.

  • Pico CSS

    Native controls that are themed, on a styled base instead of a stripped reset.

Works with your stack

An Eleventy plugin scans the built HTML after each build. A command-line compiler handles any static site. Web components get the same tokens, modes and atomic classes inside their shadow roots.

Ways to connect · Web components

import a11yAtomic from "illustion-ui/eleventy";

eleventyConfig.addPlugin(a11yAtomic, {
  out: "css/illustionui.css",
});
